# Mode declarations

One JSON file per configuration mode (ADR 0006). A mode is declarative input
only: typed network values, a small set of whitelisted generated files and
`requires`/`conflicts` tokens. There is no field for a shell command, an
arbitrary UCI line or an arbitrary upload path, and `src/lib/build/modes.ts`
rejects unknown keys.

Base presets (`minimal`, `common`, `router-default`) are not files; they live in
`src/lib/build/modes.ts` because each plan starts from exactly one of them.

## Schema

| field | meaning |
| --- | --- |
| `id`, `layer`, `title`, `experimental` | must match `config/capabilities/targets.json`; `npm run capabilities:validate` enforces it |
| `description` | user-facing explanation |
| `exclusiveGroup` | two modes in the same group cannot be combined (409) |
| `requires` | tokens that must all hold |
| `requiresAny` | OR groups: at least one token per group must hold |
| `conflicts` | tokens that must not hold |
| `network` | typed patch merged into the base network section; later overlays win, form overrides win last |
| `generatedFiles` | image paths the mode may write; must be in the whitelist below |
| `branding` / `nas` / `secret` | typed payloads for `/etc/openwrt_release`, `/etc/config/samba4` and the per-build HTTPS key |
| `packages` / `kernelConfig` | filled by ticket 08; ignored by the ticket 07 planner |

Requirement tokens: `mode:<id>`, `capability:<id>`, `engine:<source|imagebuilder>`,
`filesystem:<ext4|squashfs>`, `artifact:<combined|rootfs|...>`,
`feature:<default-wan|dhcp-server>`.

Generated file whitelist (image paths; plans prefix them with `files/`):

- `/etc/uci-defaults/90-combinewrt-modes` — the typed network section
- `/etc/openwrt_release` — branding identity only
- `/etc/config/samba4` — default Samba share, no disk operations

The HTTPS certificate and private key are never generated by the planner: the
plan carries only a `secret` spec and the workflow materialises the pair inside
the image (ADR 0004), so neither the plan nor the source offer contains key
material.
